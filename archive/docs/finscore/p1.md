I want to use langchain (latest, most up-to-date version!) to submit news articles to an LLM (like gpt-5-chat-latest) for classification. These class labels will be used later to fine-tune a smaller, custom model (LLM) for classification.

There are some example input articles in the folder 'prompts/ex/articles'  
There is an example output file in 'prompts/ex/example_type_labels.jsonl'  
The prompt I would like to use is in 'classify/prompt1.md'. The class schema is described in the prompt.  

In the future I may want to classify articles again using a different prompt/schema, so make the code versatile enough that I can rerun with a new prompt/schema.

The actual articles to be used for input are stored in the 'output/alpaca' folder. This folder has a huge number of articles (almost 20,000) so each time the classifier is run I just want to select a small random subset (~100-500) of articles to classify. This should be a parameter.

Each run should produce its own *.jsonl file with labels and save it in the 'classify/labels' folder.  
Each run should first check all existing labels files in the 'classify/labels' folder and not rerun any article that has already been classified.

The prompt is written so that either a single article or multiple articles can be submitted to LLM at one time (batch_size).  This should be another parameter.

Code should be written to submit batches asynchronously to LLM, so multiple batches can be running at once, for speed.  
The max number of concurrent batches should be another parameter.  

All new code should be placed in the 'classify' folder.
Try to keep things simple - the fewer python files the better.
