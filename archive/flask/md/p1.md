# Flask App for News Article Viewing & Labelling

## Background

I'm working on is an automatic stock trading system. One part of it involves handling financial news that comes in on a websocket connection.  Hundreds in a single day. Stored in 'output/alpaca'. I want to be able to handle these intelligently... filter out the noise from the good stuff.  Noise might be uninformative articles (e.g. "if you had invested in this stock 5 years ago, this is how much you would have now!"), or old news (i.e. articles that came out last week, so not fresh), just to give 2 examples of noise. As a first step, I want to label a subset of these articles manually. To facilitate that, I need a simple Flask app.

## 1

I would like these articles to be loaded into a simple PostgreSQL database (no authentication needed). The Flask app will access the articles through the artciles table in the database. Every time the Flask app is run, it first checks to see if new JSON files (articles) have been saved that aren't yet in the table, and loads those into the table. The app should also have a "refresh" button that does the same thing.

## 2

I want to build a simple Flask interface that allows me to navigate through each news article and label it with multiple fields. The user's labels should be saved to the database. I would like the additional fields/columns added to the articles table to NOT be "set in stone" so it's easy to add new columns in the future. There should be a "config" page in the app where the user can add/remove these fields. The user should be able to choose the name of the field, the type of the field, and the default value.  When the use adds or removes a field, this will require making modifications to the underlying database.

## 3

The Flask interface should allow searching/filtering based on these fields. That means that when fields are added or removed, the search interface needs to adapt dynamically so it always reflects the current fields in the articles table.
